# RiverLB 1.0.1

This experimental release replaces the previously mixed 1.0.1 downloads with
application packages, installation media and a signed update built from one
1.0.1 release commit. Use the signed SHA256SUMS and release-manifest.json to
verify artifact identity. The installer and RPMs contain the publisher public
trust key; no private signing key is distributed.

The release includes HTTPS-only remote management, the patched TLS verifier and
TLS dependencies, independent source login limits, management connection/upload
deadlines, and recurring security scans. Remote HTTP installations must migrate
to HTTPS before upgrading; HTTP remains available on loopback for development.
See the [security guide](../security-and-database.md#upgrade-from-remote-http-management).

The signed .rlbupdate replaces the standalone application and embedded web UI.
It does not update operating-system packages, service units or HA integration.
Use the RPMs or installer for those changes. HA application activation remains
unsupported. Preserve a backup and console access before upgrading.

The source history on main is consolidated into one 1.0.1 release commit; the
maintainer retains the preceding Git history separately. Existing dependency
pull requests are not incorporated solely by flattening history.

RPM/container and ISO structure checks do not qualify a deployed appliance.
The release remains a prerelease. BIOS/UEFI boot, graphical installation,
platform fencing, recovery and capacity qualification remain separate work.
See [release preparation](../release-readiness.md).
